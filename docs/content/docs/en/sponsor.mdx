worma is a fully open-source OpenAPI code generator released under the MIT license. All features are free forever, maintained by community contributors in their spare time.

## Why your support matters

Open source may look "free", but continuous development and maintenance take a lot of time and energy:

- **Feature iteration**: adapt to new frontend frameworks, request libraries, and backend languages
- **Docs maintenance**: multi-language docs, sample updates, video tutorials
- **Community support**: GitHub Issues / Discussions replies, PR reviews
- **Infrastructure**: domains, CDN, CI/CD server costs

Every bit of support lets maintainers focus more on development and take worma further.

## Sponsor tiers

### 🌟 Individual ($5 / month)

- A `Sponsor` badge on GitHub
- Priority on your submitted issues
- Access to an exclusive Discord channel

### 💎 Gold ($50 / month)

- Everything in Individual
- Your name / Logo shown on the README and docs home
- One 30-minute 1v1 tech consult per quarter

### 🏢 Corporate ($200 / month)

- Everything in Gold
- Logo on the site home (with link)
- Priority feature evaluation and scheduling
- One 2-hour team training per year
- Tax-deductible invoice provided

> All sponsorship is voluntary and does not affect any worma feature. 100% of sponsorship goes to project development and maintenance.

## Other ways to help

If direct sponsorship is not convenient, these matter just as much:

- **Code contribution**: find the `good first issue` label in [GitHub Issues](https://github.com/alovajs/devtools/issues)
- **Docs translation**: help improve multi-language docs
- **Share & promote**: share worma in tech communities, blogs, and social media
- **Bug reports**: submit high-quality bug reports or feature requests
- **Star**: star [alovajs/devtools](https://github.com/alovajs/devtools)

Every contribution, big or small, deserves to be remembered.
